# SketchBend

SketchBend utilizes real-time geometry processing and automatic curve fitting for rapid, adaptive modeling by the builder or designer.

With SketchBend, you get a lightweight tool that stays out of your way.

## Installation

1. Clone the repository: `git clone https://github.com/innayakendya/SketchBend.git`
2. `cd SketchBend`
3. Install in editable mode: `pip install -e .`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
